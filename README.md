# WorkProof

아르바이트 근무 기록과 예상 급여를 관리하는 모바일 앱입니다.

## 주요 기능

- 로그인 및 회원가입
- 근무지 등록
- 출퇴근 기록
- 예상 급여 계산
- 실제 입금액 비교
- 증빙 자료 및 리포트 관리

## 실행 방법

```bash
cd mobile/frontend
npm install
npx expo start
```

## Local development files

- 로컬 참고 문서, 디자인 자료, 외부 도구는 Git 저장소 밖에서 관리합니다.
- 저장소에는 앱 실행과 협업에 필요한 추적 파일만 유지합니다.
- `.env`, 개인 설정, PDF 자료, 외부 도구 복사본은 커밋하지 않습니다.
- 로컬 보관 경로는 개발자 환경마다 다를 수 있습니다.
